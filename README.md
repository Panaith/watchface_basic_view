# Watch Face Basic View

A minimalist, battery-efficient digital watch face for Wear OS, built with Watch Face Format v2.

- What is in this repository and how the apps fit together: [documentation/overview.md](documentation/overview.md)
- Build and run the watch face: [watchface/documentation/overview.md](watchface/documentation/overview.md)
- Working with AI agents: run `.\ai_tooling\setup.ps1` once from the repository root (Windows), see [ai_tooling/documentation/overview.md](ai_tooling/documentation/overview.md)
